# 모루와 세리

검을 두드려 값을 올리고, 사흘마다 찾아오는 세리에게 세금을 바치는 2D 픽셀아트 웹게임입니다.
TypeScript + Canvas 2D로 만들었고, 그림은 전부 코드로 그립니다(이미지 파일 없음).

참고한 게임플레이 영상에서 **구성만** 빌렸습니다: 확률로 갈리는 검 강화, 달력의 납부일, 유물 진열장.
이름·문구·그림·수치는 모두 새로 만들었습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 빌드 (dist/)
npm test         # 규칙 로직 테스트
npm run e2e      # 빌드 후 브라우저 자동 플레이 테스트 (Playwright)
```

주소 뒤에 붙일 수 있는 옵션: `?seed=4`(같은 시드는 같은 판), `?autostart`(타이틀 건너뛰기), `?speed=6`(연출 배속, 테스트용).

## 규칙

- 계약은 21일. 하루에 10번 두드릴 수 있습니다.
- 한 번 두드리면 파괴 · 손상(−1) · 유지 · 성공(+1) · 대성공(+2) 중 하나가 나옵니다. 단계가 높을수록 파괴 확률이 커집니다.
- 검은 단계마다 값이 1.5배가 됩니다. 언제든 팔아 골드로 바꾸고 +0 검으로 다시 시작할 수 있습니다. 검은 날이 바뀌어도 그대로 남습니다.
- 3일마다 세금을 냅니다(7번, 300 G에서 11,000 G까지). 못 내면 게임오버, 21일차 세금까지 내면 클리어.
- 시작할 때 유물 하나를 무료로 고르고, 세금을 낼 때마다 진열장에서 유물을 살 수 있습니다(10종).

## 조작

| 화면 | 키 |
|---|---|
| 타이틀 | Enter / Space 시작 |
| 유물 선택 · 진열장 | ← → 고르기, Enter 선택·구매, 1·2·3 바로 선택, R 새로 들이기, N 대장간으로 |
| 대장간 | Space / Enter 두드리기, S 팔기, N 하루 넘기기 |
| 세금 | Enter 계속 |
| 게임오버 · 클리어 | R / Enter 다시 시작 |

## 영상과 다른 점

- 3D 1인칭이 아니라 고정 화면 2D입니다. 걸어 다니지 않고 키로 바로 행동합니다.
- 검을 여러 자루 들고 다니지 않습니다. 검은 한 자루이고, 세금은 검이 아니라 골드로 냅니다.
- 유물 값은 검이 아니라 골드입니다. 소모품, 저장 슬롯, 검 외형의 세부 진화는 없습니다.
- 계약 기간, 확률, 세금, 유물 효과는 자체 설계한 수치입니다.

## 구조

- `src/game/` — 화면과 무관한 규칙. `reduce(state, action)` 하나로만 상태가 바뀝니다.
- `src/render/` — 480×270 캔버스에 그리는 픽셀아트와 이펙트.
- `window.__game` — 읽기 전용 상태 스냅샷(테스트가 읽습니다).
